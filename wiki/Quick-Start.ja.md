## Tako をインストールする

一部の対応サイトには年齢制限のあるコンテンツがあります。ストアで Tako が成人向けと表示される場合は、対象年齢を満たす Google アカウントでログインしてください。

1. Chrome 150 以降で [Chrome ウェブストアの Tako](https://chromewebstore.google.com/detail/tako-manga-downloader/hlodmckfkmbenkknmailfekehgajpmbb) を開きます。
2. **Chrome に追加**をクリックします。
3. Chrome の拡張機能メニューを開き、見つけやすいように Tako のアイコンを固定します。

<details>
<summary>GitHub のリリースをインストールする</summary>

1. [GitHub Releases](https://github.com/oovz/Tako/releases) を開き、使いたいリリースの Chrome 用 ZIP ファイルをダウンロードします。
2. パソコン上のフォルダに展開します。
3. `chrome://extensions` を開き、**デベロッパー モード**を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**をクリックし、展開したフォルダを選びます。

拡張機能を削除するまでは、展開したフォルダを移動せずに残してください。ローカルでビルドする場合は、[開発環境の準備](https://github.com/oovz/Tako/blob/main/CONTRIBUTING.md#quick-setup)をご覧ください。

## 初めてのダウンロード

1. [対応サイト](Supported-Sites.ja)で漫画を開きます。多くのサイトでは作品ページを、少年ジャンプ＋ではエピソードページを開いてください。
2. Tako アイコンをクリックし、Chrome のサイドパネルを開きます。
3. **マンガ**を開き、保存したい話を選んで**ダウンロード**をクリックします。
4. **キュー**で進捗を確認し、**最近**で保存済みの話を確認します。

サイドパネルは**キュー**から開きます。現在のタブが対応する作品ページの場合、**マンガ**が表示されます。待機中のタスクのハンドルをドラッグして順序を変えるか、クリックして位置を入力できます。**最近**には保存済みの話が表示され、設定の全履歴を開けます。

初期設定では、Chrome のダウンロード機能を使って CBZ ファイルを保存します。CBZ は対応する漫画リーダーで開けます。

> [!TIP]
> MangaDex は初期状態では無効です。**オプション → サイト統合**で有効にし、Chrome の確認画面でサイトへのアクセスを許可して、**変更を保存**をクリックしてから作品ページに戻ってください。

## 形式を選ぶ

サイドパネルの**設定**を開くか、Tako アイコンを右クリックして**オプション**を選びます。**ストレージとファイル**でアーカイブ形式を選び、**変更を保存**をクリックします。

| 形式               | 用途                                   |
| ------------------ | -------------------------------------- |
| **CBZ**            | 漫画リーダーで話を読む                 |
| **ZIP**            | 話の画像を標準的なアーカイブにまとめる |
| **アーカイブなし** | 個別の画像ファイルとして保存する       |

対応するリーダー用に、作品の表紙や ComicInfo.xml 形式のメタデータを含めることもできます。[ファイル名のテンプレート](Template-Macros.ja)で、フォルダの構成や話の名前を設定できます。

## 保存先のフォルダを選ぶ

**オプション → ストレージとファイル**で、Chrome の保存先を使う場合は**ブラウザダウンロードを使用**を選びます。別のフォルダに保存する場合は**カスタムフォルダを使用（File System Access）**を選び、フォルダを指定します。**変更を保存**をクリックすると、新しいダウンロードに適用されます。

ダウンロード中にも既定の設定を変更できます。キューに入っているタスクは、再試行や再実行の際も、元のフォルダと指定済みのファイル名を使います。別の場所に保存するには、既定の設定を変更して新しいタスクを作成してください。

**フォルダーが使用できない場合は Chrome ダウンロードを使う**は、必要に応じて有効にする設定です。初期状態では無効です。新しいタスクに適用され、タスクが指定のフォルダへの書き込みを初めて試みる前に限り、保存先を切り替えられます。

## ダウンロードを管理する

続けてダウンロードするには、別の作品を開くか、同じ作品の別の話を選び、もう一度 **ダウンロード** をクリックします。Tako はキューに入った話を 1 話ずつ処理します。保存中は Chrome を起動したままにしてください。

- **失敗した章を再試行**を選ぶと、タスクの未完了の部分を再度ダウンロードします。一部だけ保存された話は、その話の最初からやり直します。
- **タスクをやり直し**を選ぶと、そのタスクのすべての話をダウンロードし直します。
- **ダウンロードをキャンセル**を選ぶと、タスクの残りの処理を止めます。保存済みのファイルは残り、Chrome が受け付けた転送は Chrome のダウンロード機能で続きます。
- オプションの**アクティビティと履歴**で、過去のタスクや話の記録を確認できます。

フォルダへのアクセスエラー、中断された処理、**以前に処理済み**の表示については、[トラブルシューティング](Troubleshooting.ja)をご覧ください。
