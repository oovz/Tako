## Tako をインストールする

1. Chrome 150 以降で [Chrome ウェブストアの Tako](https://chromewebstore.google.com/detail/tako-manga-downloader/hlodmckfkmbenkknmailfekehgajpmbb) を開きます。
2. **Chrome に追加**をクリックします。
3. Chrome の拡張機能メニューを開き、見つけやすいように Tako のアイコンを固定します。

<details>
<summary>GitHub のリリースをインストールする</summary>

1. [GitHub Releases](https://github.com/oovz/Tako/releases) を開き、使いたいリリースの Chrome 用 ZIP ファイルをダウンロードします。
2. パソコン上のフォルダに展開します。
3. `chrome://extensions` を開き、**デベロッパー モード**を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**をクリックし、展開したフォルダを選びます。

拡張機能をインストールしている間は、そのフォルダを移動せずに置いてください。ローカルでビルドする場合は、[開発環境の準備](https://github.com/oovz/Tako/blob/main/CONTRIBUTING.md#quick-setup)をご覧ください。

## 初めてのダウンロード

1. [対応サイト](Supported-Sites.ja)で漫画を開きます。多くのサイトは作品ページを使います。少年ジャンプ＋はエピソードページを使います。
2. Tako アイコンをクリックし、Chrome のサイドパネルを開きます。
3. 保存したい話を選び、**ダウンロード**をクリックします。
4. キューで進捗を確認します。保存が完了すると、**保存済み**または**フォルダーに保存済み**と表示されます。

初期設定では、Chrome のダウンロード機能を使って CBZ を保存します。CBZ は対応する漫画リーダーで開けます。

> [!TIP]
> MangaDex は初期状態では無効です。**オプション → サイト統合**で有効にし、Chrome のサイトアクセス要求を許可して、**変更を保存**をクリックしてから作品ページに戻ってください。

## 形式を選ぶ

サイドパネルの**設定**を開くか、Tako アイコンを右クリックして**オプション**を選びます。**ストレージとファイル**でアーカイブ形式を選び、**変更を保存**をクリックします。

| 形式               | 用途                                   |
| ------------------ | -------------------------------------- |
| **CBZ**            | 漫画リーダーで話を読む                 |
| **ZIP**            | 話の画像を標準的なアーカイブにまとめる |
| **アーカイブなし** | 個別の画像ファイルとして保存する       |

対応するリーダー向けに、作品の表紙や ComicInfo.xml メタデータを含めることもできます。[ファイル名のテンプレート](Template-Macros.ja)で、フォルダや話の名前の付け方を設定できます。

## 保存先のフォルダを選ぶ

**オプション → ストレージとファイル**で、Chrome の保存先を使う場合は**ブラウザダウンロードを使用**を選びます。別のフォルダに保存する場合は**カスタムフォルダを使用（File System Access）**を選び、フォルダを指定します。**変更を保存**をクリックすると、新しいダウンロードに適用されます。

ダウンロード中にも既定設定を変更できます。キューに入っているタスクは、再試行や再実行も含め、元のフォルダと指定済みのファイル名を保持します。別の場所に保存するには、既定設定を変更して新しいタスクを作成してください。

**フォルダーが使用できない場合は Chrome ダウンロードを使う**は、新しいタスクに適用される任意の設定です。初期状態では無効で、タスクが選択したフォルダへの最初の書き込みを試みる前に限り、保存先を切り替えられます。

## ダウンロードを管理する

Tako は一度に一話ずつ処理します。処理中にも、キューに話を追加できます。 保存中は Chrome を起動したままにしてください。

- **失敗した章を再試行**すると、未完了の部分を再度ダウンロードします。一部だけ保存された話は、その話の最初からやり直します。
- **タスクをやり直し**すると、そのタスクのすべての話をダウンロードし直します。
- **ダウンロードをキャンセル**すると、タスクの残りの処理を止めます。保存済みのファイルは残り、Chrome が受け付けた転送は Chrome のダウンロード機能で続きます。
- オプションの**アクティビティと履歴**で、過去のタスクや話の記録を確認できます。

フォルダへのアクセスエラー、中断された処理、**以前に処理済み**の表示については、[トラブルシューティング](Troubleshooting.ja)をご覧ください。
