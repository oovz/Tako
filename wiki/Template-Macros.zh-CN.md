# 模板宏

[English](Template-Macros) · [日本語](Template-Macros.ja) · [简体中文](Template-Macros.zh-CN) · [繁體中文](Template-Macros.zh-TW) · [한국어](Template-Macros.ko)

> 本页由[英文原文](Template-Macros)机器翻译而来。

模板决定 Tako 下载章节时使用的文件夹和名称。宏是 `<SERIES_TITLE>` 这样的占位符，Tako 会将它替换为漫画的相关信息。

## 从默认设置开始

打开**选项 → 存储与文件**，其中有两个模板字段：

| 字段             | 默认值               | 控制内容                                         |
| ---------------- | -------------------- | ------------------------------------------------ |
| **目录路径模板** | `TMD/<SERIES_TITLE>` | 下载位置下的文件夹                               |
| **文件名模板**   | `<CHAPTER_TITLE>`    | 章节压缩包名称，或保存单独图片时使用的章节文件夹 |

对于名为 _Example Manga_ 的系列和名为 _Chapter 1_ 的章节，默认模板生成：

```text
TMD/Example Manga/Chapter 1.cbz
```

格式单独选择。Tako 会自动添加 `.cbz` 或 `.zip`。选择**不打包**时，章节名称会成为存放图片的文件夹名。

目录字段中用 `/` 分隔文件夹。在该字段写入 `.cbz` 会创建带有这一后缀的文件夹。

## 可尝试的模板

| 目标                   | 目录模板                            | 文件名模板                                   |
| ---------------------- | ----------------------------------- | -------------------------------------------- |
| 按系列分组             | `TMD/<SERIES_TITLE>`                | `<CHAPTER_TITLE>`                            |
| 先按网站、再按系列分组 | `<INTEGRATION_NAME>/<SERIES_TITLE>` | `<CHAPTER_TITLE>`                            |
| 按下载月份分组         | `<YYYY>/<MM>/<SERIES_TITLE>`        | `<CHAPTER_TITLE>`                            |
| 添加章节编号           | `TMD/<SERIES_TITLE>`                | `Ch.<CHAPTER_NUMBER_PAD3> - <CHAPTER_TITLE>` |

带编号的名称需要网站提供章节编号。如果网站未提供，请使用默认的标题模板。

## 可用宏

### 日期宏

日期宏使用创建任务时的本地日期。重试和重新开始会保留原先请求的路径，即使操作日期已改变。

| 宏       | 含义     | 示例   |
| -------- | -------- | ------ |
| `<YYYY>` | 四位年份 | `2026` |
| `<MM>`   | 两位月份 | `05`   |
| `<DD>`   | 两位日期 | `12`   |

### 网站与系列宏

| 宏                   | 含义                        | 可用情况         |
| -------------------- | --------------------------- | ---------------- |
| `<INTEGRATION_NAME>` | 站点标识符，例如 `mangadex` | 队列下载可用     |
| `<SERIES_TITLE>`     | 漫画或系列标题              | 队列下载可用     |
| `<PUBLISHER>`        | 出版社名称                  | 取决于网站元数据 |

### 章节与卷宏

| 宏                      | 含义                   | 示例                 |
| ----------------------- | ---------------------- | -------------------- |
| `<CHAPTER_TITLE>`       | 章节标题               | `Chapter 1`          |
| `<CHAPTER_NUMBER>`      | 章节编号               | `15.5`               |
| `<CHAPTER_NUMBER_PAD2>` | 补足至少两位的章节编号 | `01`                 |
| `<CHAPTER_NUMBER_PAD3>` | 补足至少三位的章节编号 | `001`                |
| `<VOLUME_NUMBER>`       | 卷编号                 | `5`                  |
| `<VOLUME_NUMBER_PAD2>`  | 补足至少两位的卷编号   | `05`                 |
| `<VOLUME_TITLE>`        | 卷标题                 | 目前在队列下载中为空 |

队列下载可使用章节标题。章节编号和卷编号取决于网站元数据。模板编辑器识别 `<VOLUME_TITLE>`，但队列下载目前会将它留空；有卷编号时可以使用对应的数字宏。

## 缺失值

不可用的值会变成空文本。Tako 会去掉空的目录段，但保留文件名中周围的文字。例如，没有章节编号时，`Ch.<CHAPTER_NUMBER_PAD3> - <CHAPTER_TITLE>` 可能变成 `Ch. - Chapter 1`。

预览使用示例数据；实际值取决于网站元数据。

## 保存更改

编辑模板后，点击**保存更改**。修改适用于新任务；队列中的任务以及重试、重新开始的任务会保留已记录的请求路径。Chrome 的保存对话框或已有文件处理设置仍可能影响最终文件名。

Tako 会把文件名中不可用的字符替换为下划线。未知宏、空模板和不可用的路径会提示错误。
