# Tako を選ぶ

[English](Comparisons) · [日本語](Comparisons.ja) · [简体中文](Comparisons.zh-CN) · [繁體中文](Comparisons.zh-TW) · [한국어](Comparisons.ko)

このページは[英語版](Comparisons)から機械翻訳されています。

Tako は Chrome で閲覧しながら漫画を保存したい読者向けの拡張機能です。ページの横にあるサイドパネルで、話の選択と進捗の確認ができます。

## 自分の読み方に合っていますか？

| やりたいこと                                 | Tako でできること                                                  |
| -------------------------------------------- | ------------------------------------------------------------------ |
| 画像を一枚ずつ操作せず、複数の話を保存したい | 話を選んでキューに追加できます                                     |
| ダウンロードした話を漫画リーダーで読みたい   | 表紙や ComicInfo.xml メタデータを付けた CBZ を出力できます         |
| 使い慣れた形式で画像を保存したい             | ZIP または個別の画像ファイルを選べます                             |
| ローカルの漫画フォルダを整理したい           | 保存先と、フォルダ名・ファイル名のテンプレートを設定できます       |
| 未完了の話を再度ダウンロードしたい           | 失敗した話の再試行や、記録された保存先でのタスクの再実行ができます |
| ダウンロードの結果を確認したい               | オプションで保存結果とエピソード履歴を確認できます                 |

## インストール前に確認すること

Tako は Chrome 150 以降で動作し、[対応サイト](Supported-Sites.ja)を利用できます。保存できる話は、各サイトの統合機能と、ウェブ版リーダーで利用できるアクセス権によって決まります。

ダウンロードする話を選び、保存中は Chrome を起動したままにしてください。キューと履歴はブラウザを再起動しても残ります。中断された処理は再試行が必要になる場合があります。

保存形式は CBZ、ZIP、個別の画像です。Chrome で話を選択すると、ダウンロードを開始できます。

## 一話試してみる

[クイックスタート](Quick-Start.ja)に沿って一話ダウンロードし、普段使うリーダーで開いてみてください。結果や保存先が分からない場合は、[トラブルシューティング](Troubleshooting.ja)で利用できる操作を確認できます。
