# 템플릿 매크로

[English](Template-Macros) · [日本語](Template-Macros.ja) · [简体中文](Template-Macros.zh-CN) · [繁體中文](Template-Macros.zh-TW) · [한국어](Template-Macros.ko)

> 이 페이지는 [영어 원문](Template-Macros)을 기계 번역한 문서입니다.

템플릿은 Tako가 다운로드한 챕터에 사용할 폴더와 이름을 정합니다. 매크로는 `<SERIES_TITLE>`처럼 만화 정보로 바뀌는 자리표시자입니다.

## 기본값으로 시작하기

**옵션 → 저장 및 파일**을 여세요. 템플릿 입력란은 두 개입니다.

| 입력란               | 기본값               | 설정 대상                                             |
| -------------------- | -------------------- | ----------------------------------------------------- |
| **폴더 경로 템플릿** | `TMD/<SERIES_TITLE>` | 다운로드 위치 아래의 폴더                             |
| **파일 이름 템플릿** | `<CHAPTER_TITLE>`    | 챕터 압축 파일 이름 또는 개별 이미지를 담을 챕터 폴더 |

작품명이 _Example Manga_, 챕터명이 _Chapter 1_이면 기본값으로 다음 경로가 만들어집니다.

```text
TMD/Example Manga/Chapter 1.cbz
```

형식은 별도로 선택합니다. Tako가 `.cbz`나 `.zip`을 자동으로 붙입니다. **압축 안 함**을 선택하면 챕터 이름의 폴더 안에 이미지가 저장됩니다.

디렉터리 입력란에서는 폴더 사이에 `/`를 사용하세요. 해당 입력란에 `.cbz`를 넣으면 그 접미사가 붙은 폴더가 만들어집니다.

## 사용해 볼 패턴

| 목적                          | 디렉터리 템플릿                     | 파일 이름 템플릿                             |
| ----------------------------- | ----------------------------------- | -------------------------------------------- |
| 작품별로 묶기                 | `TMD/<SERIES_TITLE>`                | `<CHAPTER_TITLE>`                            |
| 사이트별로 묶고 작품별로 구분 | `<INTEGRATION_NAME>/<SERIES_TITLE>` | `<CHAPTER_TITLE>`                            |
| 다운로드한 달별로 묶기        | `<YYYY>/<MM>/<SERIES_TITLE>`        | `<CHAPTER_TITLE>`                            |
| 챕터 번호 추가                | `TMD/<SERIES_TITLE>`                | `Ch.<CHAPTER_NUMBER_PAD3> - <CHAPTER_TITLE>` |

번호를 포함한 이름은 사이트가 챕터 번호를 제공할 때 사용할 수 있습니다. 제공하지 않는 경우 제목 기반 기본값을 사용하세요.

## 사용 가능한 매크로

### 날짜 매크로

작업을 만들 때의 현지 날짜를 사용합니다. 다른 날 재시도하거나 다시 시작해도 원래 요청한 경로를 유지합니다.

| 매크로   | 의미         | 예시   |
| -------- | ------------ | ------ |
| `<YYYY>` | 네 자리 연도 | `2026` |
| `<MM>`   | 두 자리 월   | `05`   |
| `<DD>`   | 두 자리 일   | `12`   |

### 사이트와 작품 매크로

| 매크로               | 의미                          | 사용 가능 여부                |
| -------------------- | ----------------------------- | ----------------------------- |
| `<INTEGRATION_NAME>` | `mangadex` 같은 사이트 식별자 | 대기열 다운로드에서 사용 가능 |
| `<SERIES_TITLE>`     | 만화 또는 작품 제목           | 대기열 다운로드에서 사용 가능 |
| `<PUBLISHER>`        | 출판사 이름                   | 사이트 메타데이터에 따라 다름 |

### 챕터와 권 매크로

| 매크로                  | 의미                                        | 예시                             |
| ----------------------- | ------------------------------------------- | -------------------------------- |
| `<CHAPTER_TITLE>`       | 챕터 제목                                   | `Chapter 1`                      |
| `<CHAPTER_NUMBER>`      | 챕터 번호                                   | `15.5`                           |
| `<CHAPTER_NUMBER_PAD2>` | 앞에 0을 붙여 최소 두 자리로 만든 챕터 번호 | `01`                             |
| `<CHAPTER_NUMBER_PAD3>` | 앞에 0을 붙여 최소 세 자리로 만든 챕터 번호 | `001`                            |
| `<VOLUME_NUMBER>`       | 권 번호                                     | `5`                              |
| `<VOLUME_NUMBER_PAD2>`  | 앞에 0을 붙여 최소 두 자리로 만든 권 번호   | `05`                             |
| `<VOLUME_TITLE>`        | 권 제목                                     | 현재 대기열 다운로드에서는 빈 값 |

챕터 제목은 대기열 다운로드에서 사용할 수 있습니다. 챕터 번호와 권 번호는 사이트 메타데이터에 따라 달라집니다. 템플릿 편집기는 `<VOLUME_TITLE>`을 인식하지만 현재 대기열 다운로드에서는 빈 값으로 남습니다. 권 번호를 제공하는 경우 숫자 매크로를 사용하세요.

## 값이 없는 경우

사용할 수 없는 값은 빈 텍스트가 됩니다. Tako는 비어 있는 폴더 구간을 제거하지만 파일 이름의 주변 텍스트는 유지합니다. 예를 들어 챕터 번호가 없으면 `Ch.<CHAPTER_NUMBER_PAD3> - <CHAPTER_TITLE>`은 `Ch. - Chapter 1`이 될 수 있습니다.

미리보기는 예시 데이터를 사용하며, 실제 값은 사이트 메타데이터에 따라 달라집니다.

## 변경 사항 저장

템플릿을 수정한 뒤 **변경 사항 저장**을 클릭하세요. 변경 사항은 새 작업에 적용됩니다. 대기열에 있는 작업과 재시도·다시 시작 작업은 기록된 요청 경로를 유지합니다. 최종 파일 이름은 Chrome의 저장 대화상자나 기존 파일 처리 설정의 영향을 받을 수 있습니다.

Tako는 파일 이름에 사용할 수 없는 문자를 밑줄로 바꾸고 예약된 이름, 제어 문자, 호환되지 않는 끝부분의 마침표나 공백을 처리합니다. 알 수 없는 매크로, 빈 템플릿, 사용할 수 없는 경로에는 오류를 표시합니다.
