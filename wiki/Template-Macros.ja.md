# テンプレートマクロ

[English](Template-Macros) · [日本語](Template-Macros.ja) · [简体中文](Template-Macros.zh-CN) · [繁體中文](Template-Macros.zh-TW) · [한국어](Template-Macros.ko)

このページは[英語版](Template-Macros)から機械翻訳されています。

テンプレートで、ダウンロードする話の保存先フォルダと名前を指定できます。マクロは `<SERIES_TITLE>` のようなプレースホルダーで、Tako が漫画の情報に置き換えます。

## 初期設定から始める

**オプション → ストレージとファイル**を開きます。テンプレートの入力欄は二つあります。

| 入力欄                           | 初期設定             | 指定する内容                                             |
| -------------------------------- | -------------------- | -------------------------------------------------------- |
| **ディレクトリパステンプレート** | `TMD/<SERIES_TITLE>` | 保存先の下に作るフォルダ                                 |
| **ファイル名テンプレート**       | `<CHAPTER_TITLE>`    | 話のアーカイブ名、または個別画像を保存する話のフォルダ名 |

作品名が _Example Manga_、話のタイトルが _Chapter 1_ の場合、初期設定では次のパスになります。

```text
TMD/Example Manga/Chapter 1.cbz
```

形式は別途選びます。Tako が `.cbz` または `.zip` を自動で付けます。**アーカイブなし**では、話の名前が画像を含むフォルダ名になります。

ディレクトリ欄では、フォルダの区切りに `/` を使ってください。この欄に `.cbz` を入れると、その拡張子が付いたフォルダが作られます。

## テンプレートの例

| 目的                               | ディレクトリテンプレート            | ファイル名テンプレート                       |
| ---------------------------------- | ----------------------------------- | -------------------------------------------- |
| 作品ごとにまとめる                 | `TMD/<SERIES_TITLE>`                | `<CHAPTER_TITLE>`                            |
| サイト別、その下に作品別にまとめる | `<INTEGRATION_NAME>/<SERIES_TITLE>` | `<CHAPTER_TITLE>`                            |
| ダウンロードした月でまとめる       | `<YYYY>/<MM>/<SERIES_TITLE>`        | `<CHAPTER_TITLE>`                            |
| 話数を付ける                       | `TMD/<SERIES_TITLE>`                | `Ch.<CHAPTER_NUMBER_PAD3> - <CHAPTER_TITLE>` |

名前に話数を含めるには、サイトから話数を取得できる必要があります。取得できない場合は、話のタイトルを使う初期設定を利用してください。

## 利用できるマクロ

### 日付

タスク作成時のローカル日付を使います。日付が変わっても、再試行や再実行では元の指定パスを使います。

| マクロ   | 意味     | 例     |
| -------- | -------- | ------ |
| `<YYYY>` | 4 桁の年 | `2026` |
| `<MM>`   | 2 桁の月 | `05`   |
| `<DD>`   | 2 桁の日 | `12`   |

### サイトと作品

| マクロ               | 意味                          | 利用できる条件                         |
| -------------------- | ----------------------------- | -------------------------------------- |
| `<INTEGRATION_NAME>` | `mangadex` などのサイト識別子 | キューに追加するダウンロードで利用可能 |
| `<SERIES_TITLE>`     | 漫画・作品のタイトル          | キューに追加するダウンロードで利用可能 |
| `<PUBLISHER>`        | 出版社名                      | サイトのメタデータによる               |

### 話と巻

| マクロ                  | 意味                                 | 例                                       |
| ----------------------- | ------------------------------------ | ---------------------------------------- |
| `<CHAPTER_TITLE>`       | 話のタイトル                         | `Chapter 1`                              |
| `<CHAPTER_NUMBER>`      | 話数                                 | `15.5`                                   |
| `<CHAPTER_NUMBER_PAD2>` | 最低 2 桁になるように 0 を付けた話数 | `01`                                     |
| `<CHAPTER_NUMBER_PAD3>` | 最低 3 桁になるように 0 を付けた話数 | `001`                                    |
| `<VOLUME_NUMBER>`       | 巻数                                 | `5`                                      |
| `<VOLUME_NUMBER_PAD2>`  | 最低 2 桁になるように 0 を付けた巻数 | `05`                                     |
| `<VOLUME_TITLE>`        | 巻のラベル                           | キューに追加するダウンロードでは現在空欄 |

キューに追加したダウンロードでは、話のタイトルを利用できます。話数と巻数は、サイトのメタデータによって決まります。テンプレートエディターは `<VOLUME_TITLE>` を認識しますが、キューに追加するダウンロードでは現在空欄になります。巻数がある場合は、巻数を使うマクロを選んでください。

## 値がない場合

値を取得できないマクロは空の文字列に置き換わります。空になったフォルダの階層は省かれますが、ファイル名ではマクロの前後の文字が残ります。例えば話数がない場合、`Ch.<CHAPTER_NUMBER_PAD3> - <CHAPTER_TITLE>` は `Ch. - Chapter 1` になります。

プレビューにはサンプルデータを使います。実際の値はサイトのメタデータによって変わります。

## 変更を保存する

テンプレートを編集したら、**変更を保存**をクリックしてください。変更は新しいタスクに適用されます。既存のタスクには、再試行や再実行の際も、記録された指定パスが使われます。Chrome の保存ダイアログでの指定や、同名ファイルの設定によって、最終的なファイル名が変わる場合があります。

Tako はファイル名に使えない文字をアンダースコアに置き換えます。不明なマクロ、空のテンプレート、利用できないパスはエラーになります。
