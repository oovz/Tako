表示されたメッセージや状況に合う項目をご覧ください。初めてダウンロードする場合は、[クイックスタート](Quick-Start.ja)から始めてください。

## 話の一覧を読み込めない

1. [対応するページ](Supported-Sites.ja)を開いているか確認します。多くのサイトは作品や書籍のページを使います。少年ジャンプ＋はエピソードページを使います。
2. **オプション → サイト統合**で、そのサイトが有効になっているか確認します。MangaDex では、Chrome のサイトアクセス要求を許可して変更を保存する必要もあります。
3. パネルに**シリーズ情報を読み込めませんでした**と表示された場合は、**シリーズを再読み込み**をクリックします。

改善しない場合は、通常の方法でサイトを開き、サイト自体が利用できるか確認してください。話へのアクセスは、アカウントや地域によって変わる場合もあります。

## 保存結果の意味

| 結果                     | 意味                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------ |
| **保存済み**             | Chrome が必要なファイルの保存を完了したことを Tako が確認しました                                      |
| **フォルダーに保存済み** | 選択したフォルダに必要なファイルが書き込まれ、ストリームが閉じられました                               |
| **以前に処理済み**       | 過去の処理記録はありますが、最終的な保存は確認されていません                                           |
| **失敗／一部成功**       | 要求された出力がすべて保存される前にタスクが終了しました。タスクのエラーと各話の結果を確認してください |
| **スキップ**             | キャンセルやフォルダ保存の失敗などの後、その話は処理されませんでした                                   |

**保存済み**は、保存した時点の結果を表します。その後にファイルが移動・削除されている場合もあるため、現在の場所は Chrome のダウンロード一覧やタスクの保存先フォルダで確認してください。

## Chrome のダウンロードを待っている

Chrome のダウンロード一覧を開き、一時停止中の転送や、操作を待っている保存ダイアログがないか確認してください。Tako は Chrome の最終結果を待ってから、保存済みと記録します。

保存を**確認できなかった**と表示される場合は、再試行の前に Chrome のダウンロード一覧と保存先フォルダを確認してください。ファイルがすでにある可能性があります。再試行や再実行の操作では、重複ファイルを作る可能性があることをお知らせします。

## フォルダへのアクセス権が失われた

1. サイドパネルまたは**オプション → アクティビティと履歴**で、失敗したタスクを探します。
2. フォルダの操作を開き、**アクセスを再許可**を選びます。
3. アクセスが回復したら、**失敗した章を再試行**または**タスクをやり直し**を選びます。

再許可すると、そのタスクの元のフォルダへの権限が回復します。権限を回復してからタスクを再試行または再実行してください。

元の保存先が利用できない場合は、**オプション → ストレージとファイル**でフォルダを選び、**変更を保存**をクリックして、新しいタスクを作成してください。既存のタスクは、作成時に記録された保存先を保持します。

## ダウンロードが失敗した、または一部だけ保存された

Tako は再試行設定に従って、ダウンロードの失敗を再試行します。それでも失敗する場合は、もう一度試す前に表示されたエラーを確認してください。

- **失敗した章を再試行**が利用できる場合は、完了済みの話を保持し、失敗した話、一部だけ保存された話、再試行対象のスキップされた話を処理し直します。一部だけ保存された話は、その話の最初からやり直します。
- **タスクをやり直し**は、すべての話をもう一度処理します。

どちらも、タスクの指定パスと実際に使用する保存先を保持します。既存のファイルは、タスクに記録された同名ファイルの設定に従って扱われます。再試行する前に、一部保存された出力を確認してください。

フォルダへの保存でエラーが起きるとタスクを終了し、残りの話をスキップします。保存済みのファイルはディスクに残ります。**フォルダーが使用できない場合は Chrome ダウンロードを使う**は、タスクを作成する前に有効にする必要があります。保存先を切り替えられるのは、そのタスクが初めてフォルダへの書き込みを試みる前だけです。

## ブラウザの再起動で処理が中断された

Tako は起動時にキューと履歴を復元し、まだ実行中の可能性がある処理を確認します。ブラウザを完全に再起動した後は、未完了の画像やアーカイブをダウンロードし直す必要があります。未完了の話には**失敗した章を再試行**、選択全体のやり直しには**タスクをやり直し**を使ってください。

保存が未確認の場合は、重複を避けるため、先に既存のファイルを確認してください。

## キャンセルしても Chrome の転送が止まらない

タスクをキャンセルすると、Tako の残りの処理と後続の話を停止します。Chrome がすでに受け付けたダウンロードは続きます。それらの転送は、Chrome のダウンロード一覧で一時停止またはキャンセルしてください。保存済みのファイルは残ります。

## ファイルを残して履歴を消去する

**オプション → アクティビティと履歴**の**タスク履歴を消去**で、完了・失敗・キャンセルされたタスクの記録を消去できます。**エピソード履歴を消去**では、すべての作品の話の記録を消去できます。

それぞれ独立した操作です。タスク履歴を消してもエピソード履歴は残り、どちらの操作でもダウンロード済みのファイルはディスクに残ります。

## 問題を報告する

[不具合を報告](https://github.com/oovz/Tako/issues/new?template=bug_report.md)する際は、Tako と Chrome のバージョン、サイト名、公開されている作品 URL、表示されたメッセージ、問題が起きるまでの手順を記載してください。アカウントの認証情報や非公開のダウンロードリンクは含めないでください。
