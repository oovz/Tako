# 权限说明

[English](Permissions) · [日本語](Permissions.ja) · [简体中文](Permissions.zh-CN) · [繁體中文](Permissions.zh-TW) · [한국어](Permissions.ko)

> 本页由[英文原文](Permissions)机器翻译而来。

Chrome 请求权限，让 Tako 能够识别漫画、下载图片并保存文件。本页说明各项权限的用途。

## 网站访问

Tako 需要访问支持的网站及其图片服务，以加载系列信息和章节。

固定网站权限涵盖扩展所含站点集成声明的网站、API 和图片服务域名，包括列出的备用域名。各站点集成识别的页面和域名见[支持的网站](Supported-Sites.zh-CN)。

网站协议需要现有会话时，Tako 可以在请求中发送浏览器管理的网站 Cookie，以复用你在网站登录后建立的会话。

MangaDex 默认关闭。在**选项 → 站点集成**中启用后，Chrome 会请求 HTTPS 网站访问权限，因为 MangaDex 使用的社区图片服务器地址会变化。如果拒绝授权，MangaDex 会保持关闭。下载请求使用该站点集成声明的端点和请求策略。

关闭相关站点集成时，Tako 会移除不再需要的可选网站访问权限。扩展的固定网站权限仍保留声明。你也可以在 Chrome 的扩展程序设置中查看网站访问权限。

## 浏览器权限

| 权限                                  | Tako 的用途                                                    |
| ------------------------------------- | -------------------------------------------------------------- |
| `storage`                             | 在浏览器配置文件中保存设置、队列记录和历史                     |
| `unlimitedStorage`                    | 让队列和历史记录可以超过 Chrome 默认的扩展存储配额             |
| `sidePanel`                           | 在阅读标签页旁显示章节选择和下载进度                           |
| `tabs`                                | 读取标签页网址和标题，识别支持的漫画页面                       |
| `webNavigation`                       | 切换页面时更新章节列表                                         |
| `scripting`                           | 网址或抓取的页面不足以提供信息时，读取支持网站中必要的页面信息 |
| `offscreen`                           | 在后台处理图片、创建压缩包并写入所选文件夹                     |
| `downloads`                           | 通过 Chrome 下载保存文件，并检查保存是否完成                   |
| `notifications`                       | 启用通知后显示下载通知                                         |
| `alarms`                              | 唤醒 Tako，检查进行中的任务并恢复中断的协调工作                |
| `declarativeNetRequestWithHostAccess` | 设置受支持图片服务器需要的请求头，例如来源页面                 |

## 文件夹访问

选择自定义文件夹会打开 Chrome 的文件夹选择器。随后 Tako 可以向该文件夹及其子文件夹保存文件。文件夹引用保存在本地，并在已保存的默认设置或任务仍需要它时保留。

修改默认文件夹会影响新任务。已有任务保留原来的文件夹，**重新授予访问权限**会为该文件夹恢复权限。如果任务无法保存，请参阅[文件夹访问权限丢失](Troubleshooting.zh-CN#文件夹访问权限丢失)。

## 隐私

设置、队列记录和下载历史保存在本地。下载请求直接发往支持的网站及其图片服务。Tako 不使用开发者分析服务，也没有接收章节内容的服务器。

启用 MangaDex 后，Tako 会将 MangaDex@Home 要求的传输报告直接发送给 MangaDex。[隐私政策](https://github.com/oovz/Tako/blob/main/PRIVACY.md)说明了报告的内容。
