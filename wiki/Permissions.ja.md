# 権限

[English](Permissions) · [日本語](Permissions.ja) · [简体中文](Permissions.zh-CN) · [繁體中文](Permissions.zh-TW) · [한국어](Permissions.ko)

このページは[英語版](Permissions)から機械翻訳されています。

Chrome は、Tako が漫画を識別し、画像をダウンロードしてファイルを保存するための権限を求めます。このページでは、それぞれの用途を説明します。

## ウェブサイトへのアクセス

作品情報や話を読み込むには、対応サイトとその画像配信サービスへのアクセス権が必要です。

アクセスの対象には、対応するウェブサイト、API、画像配信サービスのほか、代替ドメインも含まれます。認識できるページとドメインは[対応サイト](Supported-Sites.ja)をご覧ください。

サイトの利用にログイン済みのセッションが必要な場合、Tako はそのサイトのログイン Cookie を使用できます。Cookie は Chrome が管理します。

MangaDex は初期状態では無効です。**オプション → サイト統合**で有効にすると、Chrome は HTTPS サイトへのアクセス権を求めます。MangaDex はコミュニティが運営する画像サーバーを使用しており、そのアドレスが変わるためです。許可しない場合、MangaDex は無効のままになります。

サイト統合を無効にすると、不要になった追加のサイトアクセス権は削除されます。拡張機能に固定で定義されたサイト権限は、そのまま残ります。Chrome の拡張機能設定からもサイトへのアクセスを確認できます。

## ブラウザの権限

| 権限                                  | Tako での用途                                                                              |
| ------------------------------------- | ------------------------------------------------------------------------------------------ |
| `storage`                             | 設定、キューの記録、履歴をブラウザのプロファイルに保存します                               |
| `unlimitedStorage`                    | キューと履歴を、Chrome の拡張機能ストレージの標準容量を超えて保存できるようにします        |
| `sidePanel`                           | 閲覧中のタブの横に、話の選択画面と進捗を表示します                                         |
| `tabs`                                | タブの URL とタイトルを読み、対応する漫画ページを識別します                                |
| `webNavigation`                       | 別のページへ移動したときに話の一覧を更新します                                             |
| `scripting`                           | URL や取得したページだけでは足りない場合に、対応サイトのページから必要な情報を読み取ります |
| `offscreen`                           | バックグラウンドで画像処理、アーカイブ作成、選択したフォルダへの書き込みを行います         |
| `downloads`                           | Chrome のダウンロード機能でファイルを保存し、保存の完了を確認します                        |
| `notifications`                       | 通知が有効な場合にダウンロード通知を表示します                                             |
| `alarms`                              | 進行中のダウンロードを確認します                                                           |
| `declarativeNetRequestWithHostAccess` | 参照元ページなど、対応する画像サーバーが必要とするヘッダーを設定します                     |

## フォルダへのアクセス

カスタムフォルダを選ぶと、Chrome のフォルダ選択画面が開きます。選択後は、そのフォルダと配下のフォルダに保存できます。選択したフォルダの情報は、設定とダウンロードで使うためにローカルに保存されます。

既定のフォルダの変更は、新しいタスクに適用されます。既存のタスクの保存先は元のフォルダのままです。**アクセスを再許可**で、そのフォルダへのアクセス権を更新できます。保存できない場合は、[トラブルシューティング](Troubleshooting.ja#フォルダへのアクセス権が失われた)をご覧ください。

## プライバシー

設定、キューの記録、ダウンロード履歴はローカルに保存されます。ダウンロード時は、対応サイトとその画像配信サービスに直接接続します。Tako は開発者によるアクセス解析を行わず、話の内容を受信するサーバーも使用しません。

MangaDex を有効にすると、MangaDex@Home が必要とする配信レポートを MangaDex に直接送信します。送信内容は[プライバシーポリシー](https://github.com/oovz/Tako/blob/main/PRIVACY.md)で説明しています。
