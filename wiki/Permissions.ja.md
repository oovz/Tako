# 権限

[English](Permissions) · [日本語](Permissions.ja) · [简体中文](Permissions.zh-CN) · [繁體中文](Permissions.zh-TW) · [한국어](Permissions.ko)

このページは[英語版](Permissions)から機械翻訳されています。

Chrome は、Tako が漫画を識別し、画像をダウンロードしてファイルを保存するための権限を求めます。このページでは、それぞれの用途を説明します。

## ウェブサイトへのアクセス

作品情報や話を読み込むため、Tako は対応サイトとその画像配信サービスへのアクセス権を必要とします。

拡張機能に含まれる固定のサイト権限は、各統合機能が宣言するウェブサイト、API、画像配信サービスのドメインと、記載された代替ドメインを対象にします。認識できるページとドメインは[対応サイト](Supported-Sites.ja)をご覧ください。

サイトのプロトコルが既存のセッションを必要とする場合、Tako は Chrome が管理するそのサイトの Cookie をリクエストに添えて送信できます。サイトへのログインで作成されたセッションを引き継ぐ仕組みです。

MangaDex は初期状態では無効です。**オプション → サイト統合**で有効にすると、Chrome は HTTPS サイトへのアクセス権を求めます。MangaDex はアドレスが変わるコミュニティ運営の画像サーバーを使用するためです。許可しない場合、MangaDex は無効のままになります。ダウンロードは、その統合機能が宣言するエンドポイントとリクエストポリシーに従います。

統合機能を無効にした際に不要になった追加のサイト権限は削除されます。拡張機能に含まれる固定のサイト権限は宣言されたままです。Chrome の拡張機能設定からもサイトへのアクセスを確認できます。

## ブラウザの権限

| 権限                                  | Tako での用途                                                                              |
| ------------------------------------- | ------------------------------------------------------------------------------------------ |
| `storage`                             | 設定、キューの記録、履歴をブラウザのプロファイルに保存します                               |
| `unlimitedStorage`                    | キューと履歴を、Chrome の拡張機能ストレージの標準容量を超えて保存できるようにします        |
| `sidePanel`                           | 閲覧中のタブの横に、話の選択画面と進捗を表示します                                         |
| `tabs`                                | タブの URL とタイトルを読み、対応する漫画ページを識別します                                |
| `webNavigation`                       | 別のページへ移動したときに話の一覧を更新します                                             |
| `scripting`                           | URL や取得したページだけでは足りない場合に、対応サイトのページから必要な情報を読み取ります |
| `offscreen`                           | バックグラウンドで画像処理、アーカイブ作成、選択したフォルダへの書き込みを行います         |
| `downloads`                           | Chrome のダウンロード機能でファイルを保存し、保存の完了を確認します                        |
| `notifications`                       | 通知が有効な場合にダウンロード通知を表示します                                             |
| `alarms`                              | 処理中のタスクの確認や、中断された調整処理の復旧のために Tako を起動します                 |
| `declarativeNetRequestWithHostAccess` | 参照元ページなど、対応する画像サーバーが必要とするヘッダーを設定します                     |

## フォルダへのアクセス

カスタムフォルダを選ぶと、Chrome のフォルダ選択画面が開きます。選択後は、そのフォルダと配下のフォルダに保存できます。フォルダの参照情報はローカルに保存され、保存済みの既定設定やタスクが必要としている間保持されます。

既定のフォルダを変えると、新しいタスクに適用されます。既存のタスクは元のフォルダを保持し、**アクセスを再許可**すると、そのフォルダの権限が更新されます。保存できない場合は、[トラブルシューティング](Troubleshooting.ja#フォルダへのアクセス権が失われた)をご覧ください。

## プライバシー

設定、キューの記録、ダウンロード履歴はローカルに保存されます。ダウンロードは対応サイトとその画像配信サービスに直接接続します。Tako は開発者のアクセス解析や、話の内容を受信するサーバーを使わずに動作します。

MangaDex を有効にすると、MangaDex@Home が必要とする配信レポートを MangaDex に直接送信します。送信内容は[プライバシーポリシー](https://github.com/oovz/Tako/blob/main/PRIVACY.md)で説明しています。
