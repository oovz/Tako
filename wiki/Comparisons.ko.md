# Tako 선택하기

[English](Comparisons) · [日本語](Comparisons.ja) · [简体中文](Comparisons.zh-CN) · [繁體中文](Comparisons.zh-TW) · [한국어](Comparisons.ko)

> 이 페이지는 [영어 원문](Comparisons)을 기계 번역한 문서입니다.

Tako는 Chrome으로 웹을 탐색하면서 만화를 저장하려는 사용자를 위한 도구입니다. 사이드 패널에서 페이지 옆에 챕터 선택과 진행 상황을 표시합니다.

## 나의 이용 방식에 맞을까요?

| 원하는 작업                                  | Tako의 기능                                                      |
| -------------------------------------------- | ---------------------------------------------------------------- |
| 이미지를 하나씩 처리하지 않고 여러 챕터 저장 | 챕터를 선택해 대기열에 추가                                      |
| 다운로드한 챕터를 만화 뷰어에서 읽기         | 표지와 ComicInfo.xml 메타데이터를 선택적으로 포함한 CBZ 내보내기 |
| 익숙한 형식으로 이미지 보관                  | ZIP 압축 파일 또는 개별 이미지 파일 선택                         |
| 로컬 만화 폴더 정리                          | 저장 폴더 선택 및 폴더·파일 이름 템플릿 설정                     |
| 완료되지 않은 챕터 다시 시도                 | 실패한 챕터를 재시도하거나 기록된 저장 위치로 작업 다시 시작     |
| 다운로드 결과 확인                           | 옵션에서 저장 결과와 챕터 기록 확인                              |

## 설치 전 확인

Tako는 Chrome 150 이상이 필요하며 [지원 사이트](Supported-Sites.ko)에서 작동합니다. 챕터 이용 가능 여부는 각 연동의 지원 범위와 사이트 웹 리더에서의 접근 권한에 따라 달라집니다.

다운로드할 챕터를 선택하고 저장하는 동안 Chrome을 실행해 두세요. 대기열과 기록은 브라우저를 다시 시작해도 유지되지만, 중단된 작업은 다시 시도해야 할 수 있습니다.

저장 형식은 CBZ, ZIP, 개별 이미지입니다. Chrome에서 챕터를 선택하면 다운로드가 시작됩니다.

## 챕터 하나로 시작하기

[빠른 시작](Quick-Start.ko)에 따라 챕터 하나를 다운로드하고 원하는 뷰어에서 열어 보세요. 결과나 저장 위치가 확실하지 않다면 [문제 해결](Troubleshooting.ko)에서 가능한 조치를 확인할 수 있습니다.
