# 문제 해결

[English](Troubleshooting) · [日本語](Troubleshooting.ja) · [简体中文](Troubleshooting.zh-CN) · [繁體中文](Troubleshooting.zh-TW) · [한국어](Troubleshooting.ko)

> 이 페이지는 [영어 원문](Troubleshooting)을 기계 번역한 문서입니다.

아래에서 해당 메시지나 상황을 찾으세요. 첫 다운로드 방법은 [빠른 시작](Quick-Start.ko)을 참고하세요.

## 챕터 목록을 불러오지 못합니다

1. [지원하는 페이지](Supported-Sites.ko)를 열었는지 확인하세요. 대부분 작품이나 책 페이지가 필요하며, Shonen Jump+ (少年ジャンプ＋)는 에피소드 페이지를 사용합니다.
2. **옵션 → 사이트 연동**에서 해당 사이트가 켜져 있는지 확인하세요. MangaDex는 Chrome의 사이트 접근 권한 요청을 승인하고 변경 사항을 저장해야 합니다.
3. 패널에 **작품을 불러오지 못했습니다**가 표시되면 **작품 다시 불러오기**를 클릭하세요.

문제가 계속되면 브라우저에서 해당 페이지를 직접 열어 사이트 자체를 이용할 수 있는지 확인하세요. 챕터를 이용할 수 있는지는 계정이나 지역에 따라 달라질 수도 있습니다.

## 저장 결과는 무엇을 뜻하나요?

| 결과                 | 의미                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------- |
| **저장됨**           | Chrome이 필요한 파일의 저장을 완료했다는 확인을 받았습니다                             |
| **폴더에 저장됨**    | 필요한 모든 파일을 선택한 폴더에 저장했습니다                                          |
| **이전 처리 기록**   | 이전 처리 기록은 있지만 최종 저장은 확인되지 않았습니다                                |
| **실패 / 일부 성공** | 요청한 결과를 모두 저장하기 전에 작업이 끝났습니다. 작업 오류와 챕터 결과를 확인하세요 |
| **건너뜀**           | 취소나 폴더 저장 실패 등의 이유로 해당 챕터를 처리하지 않았습니다                      |

**저장됨**은 저장 당시의 결과를 기록합니다. 현재 위치는 Chrome 다운로드나 작업의 폴더에서 확인하세요. 저장한 뒤 파일을 옮기거나 삭제했을 수 있습니다.

## Chrome 다운로드를 기다리고 있습니다

Chrome 다운로드를 열어 일시 중지된 전송이나 응답이 필요한 저장 대화상자가 있는지 확인하세요. Tako는 Chrome의 최종 결과를 기다린 뒤 챕터를 저장됨으로 표시합니다.

저장을 **확인하지 못했다**고 표시되면 재시도하기 전에 Chrome 다운로드와 저장 폴더를 확인하세요. 파일이 이미 있을 수 있습니다. 재시도나 다시 시작을 선택하면 중복 파일이 생길 수 있다는 안내가 표시됩니다.

## 폴더 접근 권한을 잃었습니다

1. 사이드 패널이나 **옵션 → 활동 및 기록**에서 실패한 작업을 찾으세요.
2. 해당 작업의 폴더 메뉴를 열고 **접근 권한 다시 부여**를 선택하세요.
3. 접근 권한을 복원한 뒤 **실패한 챕터 재시도**나 **작업 다시 시작**을 선택하세요.

권한을 다시 부여하면 해당 작업이 원래 폴더에 접근할 수 있게 됩니다.

원래 저장 위치를 사용할 수 없으면 **옵션 → 저장 및 파일**에서 폴더를 선택하고 **변경 사항 저장**을 클릭한 뒤 새 작업을 만드세요. 기존 작업은 원래 저장 위치를 유지합니다.

## 다운로드에 실패했거나 일부 파일만 저장되었습니다

Tako는 재시도 설정에 따라 다운로드 실패를 다시 시도합니다. 계속 실패하면 다시 시도하기 전에 표시된 오류를 확인하세요.

- **실패한 챕터 재시도**를 사용할 수 있는 경우, 완료된 챕터는 유지하고 실패한 챕터, 일부만 저장된 챕터, 재시도 가능한 건너뛴 챕터를 다시 시도합니다. 일부만 저장된 챕터는 처음부터 시작합니다.
- **작업 다시 시작**은 모든 챕터를 다시 시도합니다.

두 동작 모두 작업의 파일 이름과 저장 위치를 유지합니다. 기존 파일은 해당 작업의 파일 충돌 설정에 따라 처리하므로 다시 시도하기 전에 일부만 저장된 파일을 확인하세요.

폴더에 저장하는 중 오류가 발생하면 작업이 종료되고 남은 챕터는 건너뜁니다. 이미 저장한 파일은 디스크에 남습니다. 선택 사항인 **폴더를 사용할 수 없으면 Chrome 다운로드 사용** 설정은 작업을 만들기 전에 켜야 하며, 해당 작업이 폴더에 파일 쓰기를 처음 시도하기 전까지만 저장 위치를 전환할 수 있습니다.

## 브라우저를 다시 시작해 작업이 중단되었습니다

Tako는 시작할 때 대기열과 기록을 복원하고 아직 실행 중일 수 있는 작업을 확인합니다. 브라우저를 완전히 다시 시작한 뒤에는 완료되지 않은 이미지와 압축 파일을 다시 다운로드해야 합니다. **실패한 챕터 재시도**로 미완료 챕터를 다시 시도하거나 **작업 다시 시작**으로 선택한 모든 챕터를 다시 처리하세요.

저장이 확인되지 않은 경우 중복 파일을 피할 수 있도록 기존 파일을 먼저 확인하세요.

## 취소했는데 Chrome 전송이 계속됩니다

작업을 취소하면 Tako의 남은 작업과 이후 챕터의 처리가 중단됩니다. Chrome이 이미 수락한 다운로드는 계속됩니다. 해당 전송은 Chrome 다운로드에서 일시 중지하거나 취소하세요. 이미 저장한 파일은 디스크에 남습니다.

## 파일을 유지하면서 기록 지우기

**옵션 → 활동 및 기록**의 **작업 기록 삭제**로 완료, 실패, 취소된 작업 기록을 제거하세요. **챕터 기록 삭제**로 모든 작품의 챕터 기록을 제거하세요.

두 기능은 독립적으로 작동합니다. 작업 기록을 지워도 챕터 기록은 유지되며, 두 기능 모두 다운로드한 파일은 디스크에 남겨 둡니다.
