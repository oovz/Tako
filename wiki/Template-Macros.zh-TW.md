# 範本巨集

[English](Template-Macros) · [日本語](Template-Macros.ja) · [简体中文](Template-Macros.zh-CN) · [繁體中文](Template-Macros.zh-TW) · [한국어](Template-Macros.ko)

> 本頁由[英文原文](Template-Macros)機器翻譯而成。

範本決定 Tako 下載章節時使用的資料夾與名稱。巨集是 `<SERIES_TITLE>` 這類預留位置，Tako 會將它替換為漫畫的相關資料。

## 從預設值開始

開啟「選項 → 儲存空間與檔案」。兩個範本欄位如下：

| 欄位             | 預設值               | 控制的內容                                       |
| ---------------- | -------------------- | ------------------------------------------------ |
| **目錄路徑範本** | `TMD/<SERIES_TITLE>` | 下載位置下的資料夾                               |
| **檔名範本**     | `<CHAPTER_TITLE>`    | 章節封存檔名稱，或儲存個別圖片時的章節資料夾名稱 |

若作品名稱為 _Example Manga_、章節名稱為 _Chapter 1_，預設值會產生：

```text
TMD/Example Manga/Chapter 1.cbz
```

格式請另外選擇。Tako 會自動加入 `.cbz` 或 `.zip`。選擇「不封存」時，章節名稱會成為存放圖片的資料夾名稱。

目錄欄位以 `/` 分隔資料夾。若將 `.cbz` 填入該欄位，會建立帶有此字尾的資料夾。

## 可試用的模式

| 目的                   | 目錄範本                            | 檔名範本                                     |
| ---------------------- | ----------------------------------- | -------------------------------------------- |
| 按作品分類             | `TMD/<SERIES_TITLE>`                | `<CHAPTER_TITLE>`                            |
| 先按網站，再按作品分類 | `<INTEGRATION_NAME>/<SERIES_TITLE>` | `<CHAPTER_TITLE>`                            |
| 按下載月份分類         | `<YYYY>/<MM>/<SERIES_TITLE>`        | `<CHAPTER_TITLE>`                            |
| 加入章節編號           | `TMD/<SERIES_TITLE>`                | `Ch.<CHAPTER_NUMBER_PAD3> - <CHAPTER_TITLE>` |

編號命名需要網站提供章節編號。若網站沒有提供，請使用以標題命名的預設範本。

## 可用巨集

### 日期巨集

使用任務建立時的本機日期。即使在其他日期重試或重新開始，仍保留原本要求的路徑。

| 巨集     | 意義       | 範例   |
| -------- | ---------- | ------ |
| `<YYYY>` | 四位數年份 | `2026` |
| `<MM>`   | 兩位數月份 | `05`   |
| `<DD>`   | 兩位數日期 | `12`   |

### 網站與作品巨集

| 巨集                 | 意義                        | 可用情況                 |
| -------------------- | --------------------------- | ------------------------ |
| `<INTEGRATION_NAME>` | 網站識別碼，例如 `mangadex` | 佇列下載可用             |
| `<SERIES_TITLE>`     | 漫畫或作品標題              | 佇列下載可用             |
| `<PUBLISHER>`        | 出版者名稱                  | 取決於網站提供的中繼資料 |

### 章節與卷數巨集

| 巨集                    | 意義                     | 範例             |
| ----------------------- | ------------------------ | ---------------- |
| `<CHAPTER_TITLE>`       | 章節標題                 | `Chapter 1`      |
| `<CHAPTER_NUMBER>`      | 章節編號                 | `15.5`           |
| `<CHAPTER_NUMBER_PAD2>` | 至少補齊兩位數的章節編號 | `01`             |
| `<CHAPTER_NUMBER_PAD3>` | 至少補齊三位數的章節編號 | `001`            |
| `<VOLUME_NUMBER>`       | 卷數                     | `5`              |
| `<VOLUME_NUMBER_PAD2>`  | 至少補齊兩位數的卷數     | `05`             |
| `<VOLUME_TITLE>`        | 卷標題                   | 佇列下載目前留空 |

佇列下載可使用章節標題。章節編號與卷數取決於網站提供的中繼資料。範本編輯器可識別 `<VOLUME_TITLE>`，但佇列下載目前會將它留空；網站有提供卷數時，請使用數值型的卷數巨集。

## 缺少的值

無法取得的值會成為空白文字。Tako 會移除空白的資料夾區段，但檔名周圍的文字會保留。例如，缺少章節編號時，`Ch.<CHAPTER_NUMBER_PAD3> - <CHAPTER_TITLE>` 可能變成 `Ch. - Chapter 1`。

預覽使用範例資料，實際值取決於網站的中繼資料。

## 儲存變更

編輯範本後，請點選「儲存變更」。變更會套用至新任務；佇列任務、重試與重新開始都會保留已記錄的要求路徑。Chrome 的儲存對話方塊或既有檔案設定，仍可能影響最終檔名。

Tako 會將檔名中無法使用的字元替換為底線，並處理保留名稱、控制字元，以及不相容的結尾句點或空格。未知巨集、空白範本與無法使用的路徑都會產生錯誤。
