# 權限說明

[English](Permissions) · [日本語](Permissions.ja) · [简体中文](Permissions.zh-CN) · [繁體中文](Permissions.zh-TW) · [한국어](Permissions.ko)

> 本頁由[英文原文](Permissions)機器翻譯而成。

Chrome 會要求權限，讓 Tako 識別漫畫、下載圖片並儲存檔案。本頁說明各項權限的用途。

## 網站存取

Tako 需要存取支援網站與圖片服務，以載入作品資料和章節。

固定網站權限涵蓋已包含整合所宣告的網站、API 與圖片服務網域，以及列出的替代網域。各整合可識別的頁面與網域，請參閱[支援網站](Supported-Sites.zh-TW)。

網站通訊協定需要現有工作階段時，Tako 可在這些請求中傳送瀏覽器管理的網站 Cookie，沿用你在網站登入後建立的工作階段。

MangaDex 預設停用。若在「選項 → 網站整合」中啟用，Chrome 會要求存取 HTTPS 網站，因為 MangaDex 使用位址會變動的社群圖片伺服器。若拒絕，MangaDex 會保持停用。下載請求使用該整合宣告的端點與請求原則。

停用相關整合後，Tako 會移除不再需要的選用網站存取權限。擴充功能固定網站權限所包含的存取範圍仍會保留在宣告中。你也可以在 Chrome 的擴充功能設定中查看網站存取權限。

## 瀏覽器權限

| 權限                                  | Tako 的用途                                                    |
| ------------------------------------- | -------------------------------------------------------------- |
| `storage`                             | 在瀏覽器設定檔中保留設定、佇列與歷史紀錄                       |
| `unlimitedStorage`                    | 讓佇列與歷史紀錄可超過 Chrome 預設的擴充功能儲存配額           |
| `sidePanel`                           | 在閱讀分頁旁顯示章節選取與下載進度                             |
| `tabs`                                | 讀取分頁網址與標題，以識別支援的漫畫頁面                       |
| `webNavigation`                       | 切換網頁時更新章節清單                                         |
| `scripting`                           | 網址或擷取的頁面不足以提供資料時，讀取支援網站上的必要頁面資訊 |
| `offscreen`                           | 在背景處理圖片、建立封存檔並寫入選定資料夾                     |
| `downloads`                           | 透過 Chrome 下載功能儲存檔案，並確認儲存是否完成               |
| `notifications`                       | 啟用通知時顯示下載通知                                         |
| `alarms`                              | 喚醒 Tako 以檢查進行中的工作，恢復中斷的協調作業               |
| `declarativeNetRequestWithHostAccess` | 設定支援圖片伺服器要求的標頭，例如來源頁面                     |

## 資料夾存取

選擇自訂資料夾時，Chrome 會開啟資料夾選擇器。之後 Tako 可儲存至該資料夾及其子資料夾。資料夾參照保留在本機，並在已儲存的預設值或任務仍需要時持續保留。

變更預設資料夾會套用至新任務。現有任務保留原本的資料夾，「重新授予存取權」也會更新對該資料夾的權限。若任務無法儲存，請參閱[疑難排解](Troubleshooting.zh-TW#資料夾存取權已失效)。

## 隱私權

設定、佇列紀錄與下載歷史都保留在本機。下載請求直接傳送至支援網站與圖片服務。Tako 不使用開發者分析服務，也沒有接收章節內容的伺服器。

啟用 MangaDex 時，Tako 會將 MangaDex@Home 要求的傳輸回報直接傳送至 MangaDex。[隱私權政策](https://github.com/oovz/Tako/blob/main/PRIVACY.md)說明了回報包含的資料。
