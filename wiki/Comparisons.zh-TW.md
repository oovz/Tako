# 選擇 Tako

[English](Comparisons) · [日本語](Comparisons.ja) · [简体中文](Comparisons.zh-CN) · [繁體中文](Comparisons.zh-TW) · [한국어](Comparisons.ko)

> 本頁由[英文原文](Comparisons)機器翻譯而成。

Tako 適合希望在 Chrome 瀏覽時儲存漫畫的讀者。章節選取與下載進度都顯示在網頁旁的側邊面板。

## 符合你的閱讀方式嗎？

| 你的需求                           | Tako 的功能                                     |
| ---------------------------------- | ----------------------------------------------- |
| 一次儲存多個章節，省去逐張處理圖片 | 選取章節並加入佇列                              |
| 在漫畫閱讀器中閱讀下載的章節       | 匯出 CBZ，並可加入封面與 ComicInfo.xml 中繼資料 |
| 使用熟悉的圖片格式                 | 選擇 ZIP 封存檔或個別圖片檔案                   |
| 整理本機漫畫資料夾                 | 選擇儲存資料夾，設定資料夾與檔名範本            |
| 再次嘗試未完成的章節               | 從任務記錄的目的地重試失敗章節或重新開始任務    |
| 查看下載結果                       | 在選項中查看儲存結果與章節歷史                  |

## 安裝前確認

Tako 需要 Chrome 150 或更新版本，可用於[支援網站](Supported-Sites.zh-TW)。章節是否可用，取決於這些整合及你對各網站網頁版閱讀器的存取權限。

選取要下載的章節後，請在儲存期間保持 Chrome 執行。Tako 的佇列與歷史紀錄會在瀏覽器重新啟動後保留，但中斷的工作可能需要重試。

可用格式包括 CBZ、ZIP 與個別圖片。先在 Chrome 中選取章節，再開始下載。

## 試著下載一章

依照[快速開始](Quick-Start.zh-TW)下載一個章節，並用喜歡的閱讀器開啟。若不清楚下載結果或儲存位置，[疑難排解](Troubleshooting.zh-TW)說明了可採取的操作。
