# 빠른 시작

## Tako 설치

1. Chrome 150 이상에서 [Chrome 웹 스토어의 Tako](https://chromewebstore.google.com/detail/tako-manga-downloader/hlodmckfkmbenkknmailfekehgajpmbb)를 여세요.
2. **Chrome에 추가**를 클릭하세요.
3. Chrome의 확장 프로그램 메뉴를 열고 Tako를 고정해 아이콘을 쉽게 찾을 수 있도록 하세요.

<details>
<summary>GitHub 릴리스 설치</summary>

1. [GitHub Releases](https://github.com/oovz/Tako/releases)를 열고 원하는 릴리스의 Chrome ZIP 파일을 다운로드하세요.
2. 컴퓨터의 폴더에 압축을 푸세요.
3. `chrome://extensions`를 열고 **개발자 모드**를 켜세요.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭하고 압축을 푼 폴더를 선택하세요.

확장 프로그램을 설치한 동안에는 해당 폴더를 그대로 두세요. 로컬 빌드는 [기여자 설정 가이드](https://github.com/oovz/Tako/blob/main/CONTRIBUTING.md#quick-setup)를 참고하세요.

## 첫 챕터 다운로드

1. [지원 사이트](Supported-Sites.ko)에서 만화를 여세요. 대부분 작품 페이지를 사용하며 Shonen Jump+ (少年ジャンプ＋)는 에피소드 페이지를 사용합니다.
2. Tako 아이콘을 클릭해 Chrome 사이드 패널을 여세요.
3. 원하는 챕터를 선택하고 **다운로드**를 클릭하세요.
4. 대기열에서 진행 상황을 확인하세요. 저장이 끝나면 **저장됨** 또는 **폴더에 저장됨**이 표시됩니다.

Tako는 기본적으로 Chrome 다운로드를 통해 CBZ 파일을 저장합니다. 호환되는 만화 뷰어에서 CBZ를 열 수 있습니다.

> [!TIP]
> MangaDex는 기본적으로 꺼져 있습니다. **옵션 → 사이트 연동**에서 켜고 Chrome의 사이트 접근 권한 요청을 승인한 뒤 **변경 사항 저장**을 클릭하고 작품 페이지로 돌아가세요.

## 형식 선택

사이드 패널에서 **설정**을 열거나 Tako 아이콘을 마우스 오른쪽 버튼으로 클릭해 **옵션**을 선택하세요. **저장 및 파일**에서 압축 형식을 선택하고 **변경 사항 저장**을 클릭하세요.

| 형식           | 용도                                |
| -------------- | ----------------------------------- |
| **CBZ**        | 만화 뷰어에서 챕터 읽기             |
| **ZIP**        | 챕터 이미지를 일반 압축 파일로 보관 |
| **압축 안 함** | 개별 이미지 파일 저장               |

호환되는 뷰어를 위해 작품 표지와 ComicInfo.xml 메타데이터를 포함할 수도 있습니다. [파일 이름 템플릿](Template-Macros.ko)으로 폴더와 챕터 이름의 정리 방식을 선택할 수 있습니다.

## 저장 폴더 선택

**옵션 → 저장 및 파일**에서 **브라우저 다운로드 사용**을 유지하면 Chrome의 다운로드 위치를 사용합니다. 또는 **사용자 지정 폴더 사용(File System Access)**을 선택하고 폴더를 고르세요. **변경 사항 저장**을 클릭하면 새 다운로드에 적용됩니다.

다운로드 중에도 기본값을 바꿀 수 있습니다. 대기열에 이미 있는 작업은 재시도하거나 다시 시작할 때도 원래 폴더와 요청한 파일 이름을 유지합니다. 다른 위치에 저장하려면 기본값을 바꾸고 새 작업을 만드세요.

선택 사항인 **폴더를 사용할 수 없으면 Chrome 다운로드 사용** 설정은 새 작업에 적용됩니다. 기본적으로 꺼져 있으며, 해당 작업이 선택한 폴더에 처음 쓰기를 시도하기 전까지만 저장 위치를 전환할 수 있습니다.

## 다운로드 관리

Tako는 한 번에 챕터 하나씩 처리합니다. 처리 중에도 대기열에 챕터를 더 추가할 수 있습니다.

- **실패한 챕터 재시도**로 작업의 미완료 부분을 다시 시도하세요. 일부만 저장된 챕터는 처음부터 다시 시작합니다.
- **작업 다시 시작**으로 해당 작업의 모든 챕터를 다시 다운로드하세요.
- **다운로드 취소**로 남은 작업을 중단하세요. 이미 저장한 파일은 디스크에 남고, Chrome이 이미 수락한 전송은 Chrome 다운로드에서 계속됩니다.
- 옵션의 **활동 및 기록**에서 이전 작업과 챕터 기록을 확인하세요.

폴더 접근 오류, 중단된 작업, **이전 처리 기록** 결과는 [문제 해결](Troubleshooting.ko)을 참고하세요.
