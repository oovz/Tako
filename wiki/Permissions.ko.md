# 권한

[English](Permissions) · [日本語](Permissions.ja) · [简体中文](Permissions.zh-CN) · [繁體中文](Permissions.zh-TW) · [한국어](Permissions.ko)

> 이 페이지는 [영어 원문](Permissions)을 기계 번역한 문서입니다.

Chrome은 Tako가 만화를 식별하고 이미지를 다운로드하며 파일을 저장할 수 있도록 권한을 요청합니다. 이 페이지는 각 권한의 용도를 설명합니다.

## 웹사이트 접근

Tako는 작품 정보와 챕터를 불러오기 위해 지원 사이트와 해당 이미지 서비스에 접근해야 합니다.

사이트 접근 권한은 지원 웹사이트, API, 이미지 서비스와 대체 도메인을 포함합니다. Tako가 인식하는 페이지와 도메인은 [지원 사이트](Supported-Sites.ko)에서 확인하세요.

사이트에 기존 세션이 필요한 경우 Tako는 해당 사이트에 로그인할 때 브라우저가 관리하는 쿠키를 사용할 수 있습니다.

MangaDex는 기본적으로 꺼져 있습니다. **옵션 → 사이트 연동**에서 켜면 Chrome이 HTTPS 사이트에 대한 접근 권한을 요청합니다. MangaDex가 주소가 바뀌는 커뮤니티 이미지 서버를 사용하기 때문입니다. 요청을 거부하면 MangaDex는 꺼진 상태를 유지합니다.

해당 연동을 끄면 더 이상 필요하지 않은 선택적 웹사이트 접근 권한을 제거합니다. 확장 프로그램의 고정 사이트 권한에 포함된 접근 권한은 선언된 상태로 유지됩니다. Chrome의 확장 프로그램 설정에서도 사이트 접근 권한을 확인할 수 있습니다.

## 브라우저 권한

| 권한                                  | Tako에서의 용도                                                                         |
| ------------------------------------- | --------------------------------------------------------------------------------------- |
| `storage`                             | 브라우저 프로필에 설정, 대기열 기록, 기록 저장                                          |
| `unlimitedStorage`                    | 대기열과 기록이 Chrome의 기본 확장 프로그램 저장 용량을 넘어 늘어날 수 있도록 허용      |
| `sidePanel`                           | 읽고 있는 탭 옆에 챕터 선택과 다운로드 진행 상황 표시                                   |
| `tabs`                                | 탭 URL과 제목을 읽어 지원하는 만화 페이지 식별                                          |
| `webNavigation`                       | 다른 페이지로 이동할 때 챕터 목록 갱신                                                  |
| `scripting`                           | URL이나 가져온 페이지로 정보가 충분하지 않을 때 지원 사이트에서 필요한 페이지 정보 읽기 |
| `offscreen`                           | 백그라운드에서 이미지 처리, 압축 파일 생성, 선택한 폴더에 쓰기                          |
| `downloads`                           | Chrome 다운로드를 통해 파일을 저장하고 저장 완료 여부 확인                              |
| `notifications`                       | 알림이 켜져 있을 때 다운로드 알림 표시                                                  |
| `alarms`                              | 진행 중인 다운로드 확인                                                                 |
| `declarativeNetRequestWithHostAccess` | 참조 페이지 등 지원 이미지 서버에 필요한 헤더 설정                                      |

## 폴더 접근

사용자 지정 폴더를 선택하면 Chrome의 폴더 선택기가 열립니다. 이후 Tako는 해당 폴더와 하위 폴더에 저장할 수 있습니다. 선택한 폴더 정보는 설정과 다운로드에 사용하도록 로컬에 저장됩니다.

기본 폴더를 바꾸면 새 작업에 적용됩니다. 기존 작업은 원래 폴더를 유지하며, **접근 권한 다시 부여**는 해당 폴더의 접근 권한을 갱신합니다. 작업이 저장하지 못하면 [문제 해결](Troubleshooting.ko#폴더-접근-권한을-잃었습니다)을 참고하세요.

## 개인정보

설정, 대기열 기록, 다운로드 기록은 로컬에 저장됩니다. 다운로드 요청은 지원 사이트와 해당 이미지 서비스로 직접 전송됩니다. Tako는 개발자 분석 도구나 챕터 내용을 수신하는 서버 없이 작동합니다.

MangaDex를 켜면 Tako는 MangaDex@Home이 요구하는 전송 보고서를 MangaDex에 직접 보냅니다. 보고서에 포함되는 내용은 [개인정보 처리방침](https://github.com/oovz/Tako/blob/main/PRIVACY.md)에서 설명합니다.
