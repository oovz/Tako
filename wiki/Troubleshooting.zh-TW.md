# 疑難排解

[English](Troubleshooting) · [日本語](Troubleshooting.ja) · [简体中文](Troubleshooting.zh-CN) · [繁體中文](Troubleshooting.zh-TW) · [한국어](Troubleshooting.ko)

> 本頁由[英文原文](Troubleshooting)機器翻譯而成。

請在下方尋找對應的訊息或情況。若是第一次下載，請先閱讀[快速開始](Quick-Start.zh-TW)。

## 章節清單無法載入

1. 確認目前開啟的是[支援頁面](Supported-Sites.zh-TW)。多數網站需要作品或書籍頁；Shonen Jump+（少年ジャンプ＋）使用單篇頁面。
2. 在「選項 → 網站整合」確認網站已啟用。MangaDex 還需要同意 Chrome 的網站存取要求並儲存變更。
3. 若面板顯示「無法載入此作品」，請點選「重試載入作品」。

若問題持續，請直接開啟該網頁，確認網站本身是否可用。章節存取權限也可能受帳號或地區影響。

## 儲存結果代表什麼？

| 結果               | 意義                                                         |
| ------------------ | ------------------------------------------------------------ |
| **已儲存**         | Tako 已收到 Chrome 完成儲存必要檔案的確認                    |
| **已儲存至資料夾** | 必要檔案均已儲存至所選資料夾                                 |
| **先前已處理**     | 存在較早的處理紀錄，但未確認最終儲存結果                     |
| **失敗／部分完成** | 任務結束時，要求的輸出尚未全部儲存；請查看任務錯誤與章節結果 |
| **已略過**         | 該章節未處理，例如取消或資料夾儲存失敗之後的章節             |

「已儲存」記錄的是儲存當時的結果。請到 Chrome 下載紀錄或任務的資料夾查看檔案目前的位置；檔案在儲存後可能被移動或刪除。

## Tako 正在等待 Chrome 下載

開啟 Chrome 下載紀錄，查看是否有暫停的傳輸，或需要回應的儲存對話方塊。Tako 會等待 Chrome 的最終結果，再將章節標記為已儲存。

若 Tako 顯示「無法確認」儲存結果，重試前請先檢查 Chrome 下載紀錄與儲存資料夾。檔案可能已存在。重試或重新開始時，操作介面會提醒可能產生重複檔案。

## 資料夾存取權已失效

1. 在側邊面板或「選項 → 活動與歷史紀錄」找到失敗的任務。
2. 開啟任務的資料夾操作，選擇「重新授予存取權」。
3. 恢復存取權後，選擇「重試失敗章節」或「重新開始任務」。

授予存取權會恢復該任務原本資料夾的權限。

若原本的目的地已無法使用，請在「選項 → 儲存空間與檔案」中選擇資料夾、點選「儲存變更」，再建立新任務。現有任務會保留原本的儲存位置。

## 下載失敗或只儲存了部分檔案

Tako 會依照重試設定再次嘗試失敗的下載。若任務仍失敗，請先查看回報的錯誤，再嘗試一次。

- 若可使用「重試失敗章節」，這項操作會保留已完成章節，並重試失敗、部分儲存及符合重試條件的已略過章節。僅儲存部分內容的章節會從頭開始。
- 「重新開始任務」會再次嘗試所有章節。

兩種操作都會保留任務的檔名與儲存位置。既有檔案會依任務的檔案衝突設定處理，因此重試前請先檢查部分輸出。

資料夾儲存錯誤會結束任務，並略過剩餘章節。已儲存的檔案會保留在磁碟上。「資料夾無法使用時改用 Chrome 下載」是選用設定，必須在建立任務前啟用；它只能在任務首次嘗試寫入資料夾之前切換目的地。

## 瀏覽器重新啟動使工作中斷

Tako 啟動時會還原佇列與歷史紀錄，並檢查可能仍在執行的工作。瀏覽器完全重新啟動後，未完成的圖片與封存檔需要重新下載。可對未完成章節使用「重試失敗章節」，或使用「重新開始任務」再次嘗試所有選取的章節。

若儲存結果尚未確認，請先檢查是否已有檔案，以免重複。

## 取消後 Chrome 仍繼續傳輸

取消任務會停止 Tako 剩餘的處理與後續章節。Chrome 已接受的下載會繼續進行。請在 Chrome 下載紀錄中暫停或取消這些傳輸。已儲存的檔案會留在磁碟上。

## 清除歷史紀錄並保留檔案

在「選項 → 活動與歷史紀錄」中，使用「清除任務歷史」移除已完成、失敗與已取消的任務紀錄。使用「清除章節歷史」可移除所有作品的章節紀錄。

兩項操作彼此獨立：清除任務歷史會保留章節歷史。無論清除哪類歷史紀錄，磁碟上已下載的檔案都會保留。

## 回報問題

[提交錯誤回報](https://github.com/oovz/Tako/issues/new?template=bug_report.md)，並提供 Tako 版本、Chrome 版本、網站、公開作品網址、畫面訊息與問題發生前的操作步驟。請勿附上帳號憑證或私人下載連結。
