## 章节列表无法加载

1. 确认打开的是[支持的页面](Supported-Sites.zh-CN)。多数网站需要系列或书籍页面；Shonen Jump+（少年ジャンプ＋）使用单话页面。
2. 在**选项 → 站点集成**中确认该网站已启用。MangaDex 还需要接受 Chrome 的网站访问请求并保存更改。
3. 如果侧边栏显示**无法加载此系列**，点击**重试系列**。

如果问题仍然存在，请直接打开该网页，检查网站本身是否可用。章节访问也可能取决于账户或地区。

## 保存结果是什么意思？

| 结果                | 含义                                                       |
| ------------------- | ---------------------------------------------------------- |
| **已保存**          | Tako 收到了 Chrome 已完成保存所需文件的确认                |
| **已保存到文件夹**  | 所需文件均已保存到所选文件夹                               |
| **此前已处理**      | 存在较早的处理记录，但最终保存结果未获确认                 |
| **失败 / 部分成功** | 任务在保存全部请求输出之前结束；请查看任务错误和各章节结果 |
| **已跳过**          | 该章节未处理，例如取消任务后或文件夹保存失败后             |

**已保存**记录的是保存当时的结果。请在 Chrome 下载或任务的文件夹中查看文件目前的位置；文件在保存后可能被移动或删除。

## Tako 正在等待 Chrome 下载

打开 Chrome 下载，查看是否有暂停的传输，或等待你操作的保存对话框。Tako 会等待 Chrome 的最终结果，再将章节标记为已保存。

如果 Tako 提示保存结果**无法确认**，请在重试之前检查 Chrome 下载和保存文件夹。文件可能已经存在。重试或重新开始时会提示可能产生重复文件。

## 文件夹访问权限丢失

1. 在侧边栏或**选项 → 活动与历史**中找到失败的任务。
2. 打开该任务的文件夹操作，选择**重新授予访问权限**。
3. 权限恢复后，选择**重试失败章节**或**重新开始任务**。

授权会恢复该任务原始文件夹的访问权限。

如果原保存位置不可用，请在**选项 → 存储与文件**中选择文件夹，点击**保存更改**，再创建新任务。已有任务保留原来的保存位置。

## 下载失败或只保存了部分文件

Tako 会按照重试设置重试下载失败的内容。如果任务仍失败，请先查看报告的错误，再决定是否重试。

- **重试失败章节**可用时，会保留已完成的章节，重新尝试失败、部分保存以及符合重试条件的已跳过章节。只保存了部分内容的章节会从头开始。
- **重新开始任务**会重新尝试所有章节。

这两项操作均保留任务的文件名和保存位置。已有文件按任务的文件冲突设置处理，因此重试前请检查部分保存的内容。

文件夹保存错误会终止任务，并跳过剩余章节。已保存的文件保留在磁盘上。可选设置**文件夹不可用时使用 Chrome 下载**必须在创建任务之前启用；只有在任务首次尝试写入文件夹之前，才可以切换保存位置。

## 浏览器重启中断了任务

Tako 启动时会恢复队列和历史记录，并检查可能仍在运行的工作。浏览器完全重启后，未完成的图片和压缩包需要重新下载。使用**重试失败章节**处理未完成的章节，或使用**重新开始任务**重试所有选中的章节。

如果保存结果未确认，请先检查已有文件，以免重复保存。

## 取消任务后 Chrome 仍在传输

取消任务会停止 Tako 剩余的处理和后续章节。Chrome 已接受的下载会继续传输。请在 Chrome 下载中暂停或取消这些传输。已保存的文件保留在磁盘上。

## 清除历史而保留文件

在**选项 → 活动与历史**中，使用**清除任务历史**移除已完成、失败和已取消的任务记录。使用**清除章节历史**移除所有系列的章节记录。

这两项操作互相独立：清除任务历史会保留章节历史。无论清除哪类历史，磁盘上的下载文件都会保留。

## 报告问题

[提交错误报告](https://github.com/oovz/Tako/issues/new?template=bug_report.md)，附上 Tako 版本、Chrome 版本、网站、公开的系列网址、可见的提示，以及触发问题的步骤。请勿附上账户凭据或私有下载链接。
